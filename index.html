구독 채널을 직접 만든 그룹으로 정리하고 YouTube 구독 화면에서 골라 보세요.

익숙한 화면에서 골라 보기

  • 그룹 필터 — 여러 그룹을 함께 선택해 원하는 채널의 영상을 모아 봅니다.
  • 라이브 필터 — 전체 영상, 방송 중인 라이브, 라이브 숨김을 선택합니다.
  • 채널 정리 — 그룹 순서·색상을 바꾸고, 분류 추천을 검토한 뒤 적용하거나 JSON 파일로 백업합니다.

목록은 이 브라우저에

Google 연결로 읽은 채널 정보와 직접 만든 그룹을 브라우저에 저장합니다. 운영자 서버로 구독 목록을 보내거나 외부 AI 서비스로 분류하지 않습니다.

사용 전에 개인정보 안내를 확인하고 동의합니다. 연결 해제, Google에서 받은 정보 삭제, 전체 로컬 데이터 삭제를 직접 선택할 수 있습니다. 삭제 범위와 보관 기간은 개인정보처리방침에서 확인하세요.
