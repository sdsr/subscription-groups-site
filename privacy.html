읽고 저장하는 정보

  • Google 연결 후 계정의 YouTube 채널 식별자·이름·프로필 사진, 구독 채널 목록을 읽습니다.
  • 채널명·핸들·사진·설명·키워드·주제 정보를 필터링과 분류 추천에 사용합니다.
  • YouTube 구독 화면의 영상·채널 링크와 라이브 표시를 읽습니다. 채널을 확인할 수 없으면 해당 영상 ID나 핸들을 Google API에 보내 확인합니다.
  • 직접 만든 그룹 이름·색상·키워드·채널 분류·순서·필터 선택·실행 취소 기록과 이 안내에 대한 동의 버전을 저장합니다.

Google 계정 비밀번호를 수집하지 않으며, 외부 AI 서비스로 목록을 보내지 않습니다. 자동 분류는 브라우저에서 실행하는 규칙 기반 추천입니다.

저장 위치와 전송

목록과 설정은 해당 브라우저의 확장 저장소에 보관합니다. 운영자의 별도 서버나 기기 간 동기화 서버는 없습니다. Google 로그인과 API 요청은 Google로 전송되고, 계정·채널 이미지는 Google의 이미지 주소에서 불러옵니다.

Chrome 인증 토큰은 브라우저 인증 기능으로 관리합니다. Whale 호환 토큰은 확장 내부 메모리 또는 신뢰된 확장 컨텍스트 전용 세션 저장소에 보관합니다. 토큰은 JSON 백업에 포함하지 않습니다. 광고 추적·사용자 행동 분석 코드를 추가하지 않습니다. YouTube 웹사이트 자체의 데이터 처리는 해당 서비스의 정책을 따릅니다.

보관 기간

Google에서 받은 목록과 계정 정보는 가져온 시각으로부터 30일 이내에 다시 동기화하거나 삭제합니다. 설명·키워드·주제 등은 각각의 조회 시각을 기준으로 정리합니다. 새 동기화에 실패한 오래된 정보의 보관 시각을 임의로 연장하지 않습니다.

브라우저가 실행 중일 때 주기적으로 확인하고, 확장을 다시 시작하거나 데이터에 접근할 때도 확인합니다. 브라우저가 종료돼 있는 동안에는 코드가 실행되지 않으므로 다음 실행 시 만료 정보를 먼저 정리합니다. 조회 캐시는 이보다 짧은 유효기간을 적용합니다.

만료 정보나 API 정보 삭제 시 채널 분류도 비워집니다. 직접 만든 그룹 이름·색상·키워드는 전체 삭제를 선택할 때까지 보관합니다. 오래되거나 조회 시각을 알 수 없는 백업의 API 정보는 새 목록처럼 복원하지 않습니다.

연결 해제와 삭제

  • 연결 해제(로그아웃)는 확장의 인증 사용을 중단합니다. 기존 목록은 위 보관 기간 안에서 유지합니다.
  • API 정보 삭제는 계정·채널 목록·채널 분류·관련 캐시·실행 취소·이전 형식의 복사본을 이 브라우저에서 삭제합니다. 그룹 이름·색상·키워드는 남습니다.
  • 전체 삭제는 그룹과 설정까지 지우고 안내 동의도 초기화합니다.
  • Google 권한 철회 및 삭제는 Google에 토큰 철회를 요청하고 API 정보를 삭제합니다. 원격 철회를 완료하지 못하면 안내에 따라 Google에서 직접 확인할 수 있습니다.

삭제 기능은 확인 후 실행하며, YouTube의 구독이나 영상 자체는 삭제하지 않습니다. Google 계정의 연결된 앱 관리에서도 접근 권한을 철회할 수 있습니다. API 요청에서 연결 만료를 확인하면 추가 조회를 중단합니다. 외부에서 철회한 권한을 실시간으로 감지하지는 않으며, 갱신되지 않은 API 정보에는 위의 30일 보관 기한을 적용합니다.

사용자가 직접 내보낸 백업 파일은 확장이 삭제할 수 없습니다. 파일을 보관한 위치에서 별도로 삭제해 주세요. 확장을 제거하면 해당 브라우저의 확장 저장소가 제거됩니다.
